> 本文为网站演示内容，不代表站点作者的真实经历。

静态网站的魅力在于它的边界很清楚：内容在文件里，页面由构建生成，部署只需要把产物放到一个可以返回文件的地方。

```ts
const site = {
  content: 'markdown',
  output: 'static',
  hosting: 'edge'
};
```

## 少一点运行时

没有数据库连接、没有后台服务，也就少了许多需要被照料的部分。对于个人博客来说，这种克制通常比复杂功能更有价值。

## 内容是核心

当文章只是一个 Markdown 文件，迁移和备份都很简单。工具可以更换，但文字仍然属于自己。
